# MPLADS Risk Intelligence System — V1

This folder contains the V1 application layer for the MPLADS Risk Intelligence System.

## Files

- `app.py` — Streamlit application
- `requirements.txt` — Python dependencies
- `.streamlit/config.toml` — Streamlit appearance and runtime configuration

## Dataset

The cleaned dataset is **not included in this folder**. V1 expects the existing repository dataset at:

`data/MPLAD_cleaned_v2.csv`

## Run

From the repository root:

```bash
pip install -r v1/requirements.txt
streamlit run v1/app.py
```

## V1 UI direction

- Clean, restrained professional dashboard
- Three neutral KPI cards with semantic accents only where useful
- Risk colors follow meaning: Critical/High = red, Medium = amber/orange, Low = green, No Risk = neutral
- Horizontal risk classification instead of a pie/donut chart
- Geographic exposure uses risk-aware coloring rather than one uniform color
- Minimal headings and unnecessary descriptive branding removed
